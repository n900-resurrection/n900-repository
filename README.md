# n900-repository

apt repository with modern software for the **Nokia N900** (Maemo 5 / Fremantle, armel): curl 8, git, Python 3.11, QuickJS, gPodder,
mutt-hildon and more. Built and generated by [nokia-n900-apps](https://github.com/n900-resurrection/nokia-n900-apps) (`make repo`);
do not edit `pool/` and `dists/` by hand, they are overwritten by the next build.

## Use
The apt of the phone speaks TLS 1.0 only, so first install two packages by hand: **`curl`** (curl 8 with TLS 1.2/1.3, which does the downloading) and
**`apt-transport-curl`** (the apt method `https` that runs it). Download both `.deb` files on the computer from the repository
(`https://n900-resurrection.github.io/n900-repository/pool/main/curl/` and `.../pool/main/apt-transport-curl/`), copy them to the phone
(for example `scp` to `/home/user/`; not to MyDocs, a FAT card that cannot run programs) and install them **together, as root**:
```sh
dpkg -i curl_<version>_armel.deb apt-transport-curl_<version>_armel.deb
```
Take the **newest** version of each file in the directory. For `apt-transport-curl` that is **0.1-1maemo3 or newer**: older versions can leave the Application Manager hanging on "Preparing installation" (see below).
`apt-transport-curl` needs `curl` and the system package `apt-transport-https` (it is on a stock Maemo 5). Without `curl` the method has nothing to run
(since 0.1-1maemo2 the method says so: `install the package curl`); `/usr/share/doc/apt-transport-curl/check.sh` (also `apt-transport-curl-check`) prints the state of the installation. Sources and documentation of the package: [apt-transport-curl](https://github.com/n900-resurrection/apt-transport-curl).

Then add the source (`/etc/apt/sources.list.d/n900.list`):
```sh
deb https://n900-resurrection.github.io/n900-repository fremantle main
```
and run `apt-get update`. The repository is **not signed yet**, apt prints `Ign ... Release.gpg` and asks for `--force-yes`.

## Install file for the Application Manager
[n900-repository.install](n900-repository.install) adds the catalogue to the built-in Application Manager and offers `apt-transport-curl`
(open it from the file manager, or run `dbus-send ... hildon_application_manager.mime_open`). Syntax of a Maemo 5 install file:

```
[n900]
name = N900 Resurrection   # name in the catalogue list
uri = https://n900-resurrection.github.io/n900-repository
dist = fremantle
components = main
```

The Application Manager reads the repository with the apt of the phone, so over HTTPS this works only after **`curl` and `apt-transport-curl`** are installed (the file offers `apt-transport-curl`; the Application Manager pulls `curl` in as its dependency). Use `apt-transport-curl` **0.1-1maemo3 or newer**: up to 0.1-1maemo2 the Application Manager could hang for ever on "Preparing installation" or while refreshing the lists (the method wrote its first message to apt in two pieces). If it still hangs, install with `apt-get` in a terminal; `apt-transport-curl-check` shows what is wrong.

## Layout
```
pool/main/<package>/<package>_<version>_armel.deb
dists/fremantle/Release
dists/fremantle/main/binary-armel/Packages, Packages.gz
```
